# Project Overview

## Project Name

Maternal Moments

## Idea Statement

Maternal Moments is a landing page for expecting mothers and pregnant women that showcases AI-powered maternity photo generation. Users upload a selfie and a full-body photo, and the platform generates professional maternity portraits in multiple poses and settings—as if shot by a professional maternity photographer. The service bridges AI efficiency with photographer-curated quality, positioning AI as a tool that enhances rather than replaces professional photography.

## Core Purpose

To convert expectant mothers into paying customers by demonstrating the value of AI-assisted maternity photography. The landing page serves as a marketing asset sent to existing newborn photography clients, offering a complementary service that is either standalone (paid) or bundled free with newborn session bookings. The core problem solved: maternity portraits are expensive and time-consuming to book; this offering makes professional-quality maternity imagery accessible, affordable, and instant—while maintaining the photographer's professional eye and curation throughout the process.

# User Stories

- As an expecting mother, I want to see a clear before-and-after example of how my selfie transforms into professional maternity portraits so that I can understand the value before committing to a purchase.

- As a potential customer, I want to easily contact the photographer via WhatsApp to ask questions or book a session so that I can get personalized support without navigating a complex contact form.

- As a skeptical customer, I want to see testimonials or examples from real mothers who've used the service so that I can trust the results are genuine and worth the investment.

# Tech Stack

This is a website built with Next.js.

## Framework

Next.js 14+ (App Router) with TypeScript. Next.js provides server-side rendering for fast page loads, built-in image optimization for the maternity photo galleries, and seamless deployment to Vercel. The App Router enables clean routing for the multi-page structure (/process, /pricing, /faq, etc.).

## UI Library

React with shadcn/ui components + Tailwind CSS. shadcn/ui provides pre-built, accessible components (buttons, modals, carousels) that can be customized to match the warm, editorial design system. Tailwind CSS handles all spacing, typography, and color application. The combination allows rapid prototyping while maintaining design consistency.

## State Management

Zustand for lightweight client-side state (carousel position, mobile menu open/closed, FAQ accordion state). No complex server state needed for a marketing site.

## Animation

Framer Motion for carousel transitions, smooth scroll effects, and subtle hover animations on buttons and cards. Keep animations restrained and purposeful—no excessive motion that distracts from the photography.

## Database / Storage

Supabase (PostgreSQL) for storing testimonials, FAQ content, and maternity photo examples. Supabase's real-time capabilities allow easy updates to the testimonials and FAQ sections without redeploying. Image storage via Supabase Storage or Cloudinary for the before-and-after examples.

## Auth (if the app has accounts)

Not applicable. This is a marketing landing page with no user accounts. WhatsApp links handle customer contact.

## CMS

Contentful or Supabase (simple) for managing testimonials, FAQ, process steps, and pricing content. Allows non-technical team members to update content without touching code.

## Hosting

Vercel. Next.js is built by Vercel; deployment is seamless, fast, and includes automatic image optimization. Vercel's analytics and edge functions support future scaling (e.g., A/B testing, dynamic pricing).

## Additional Notes

- Image optimization is critical. Use Next.js `<Image>` component for all maternity photos to ensure fast load times and responsive sizing.
- Implement Open Graph meta tags for social sharing (important for word-of-mouth marketing).
- Mobile performance is paramount. Target Lighthouse scores of 90+ on mobile.
- WhatsApp link format: `https://wa.me/[PHONE_NUMBER]?text=[ENCODED_MESSAGE]`. Store phone number in environment variable.
